# Денис — AI-инфраструктура под задачу

Дашборды с AI-чатом над твоими данными. TG-боты, которые работают сами. Обработка транскриптов, документов, рутины. Research под задачу.

Read in English: [README.md](./README.md)

## Чем занимаюсь

Делаю AI-инфраструктуру под конкретную задачу. Четыре модальности:

- **Дашборды с AI-чатом** — задаёшь вопрос человеческим языком, получаешь ответ по своим цифрам
- **Telegram-боты** — работают сами, держат рутину, реагируют на события
- **Обработка данных** — транскрипты, документы, повторяющиеся процессы
- **Research / досье** — структурный разбор темы, человека, рынка

Стек: Python + Claude API + автоматизация. 8 лет в данных (SQL/Python/Streamlit), последний год — agentic AI в проде.
